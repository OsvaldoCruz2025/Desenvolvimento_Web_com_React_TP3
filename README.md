# React - Exercícios de Formulários e Inputs

Este projeto contém 12 exercícios práticos sobre formulários e inputs controlados/não controlados em React, organizados do básico ao avançado.

## 📚 Lista de Exercícios

### Básico
1. **Input Controlado Básico** - Componente com input de texto que exibe o valor em tempo real
2. **Checkbox Controlado** - Checkbox que controla texto condicional
3. **Textarea Controlado** - Área de texto com contador de caracteres e limite
4. **Select Controlado** - Dropdown com opções de cidades

### Intermediário
5. **Formulário de Login** - Form com email e senha, prevenindo submit padrão
6. **Input Não Controlado com Ref** - Uso de useRef para acessar valor do input
7. **Múltiplos Inputs Controlados** - Gerenciamento de múltiplos campos (nome, email, telefone)
8. **Validação Simples** - Validação de senhas com feedback visual
9. **Elevação de Estado** - Componentes pai e filho compartilhando estado
10. **Formulário com Múltiplos Tipos** - Todos os tipos de input (text, number, checkbox, select, textarea)

### Avançado
11. **Lista de Tarefas com Formulário** - CRUD completo com filtros e prioridades
12. **Formulário de Cadastro com Validação** - Validação complexa em tempo real com múltiplos campos

## 🚀 Como Executar

```bash
# Instalar dependências
pnpm install

pnpm dev
```

## 💡 Conceitos Abordados

- ✅ Inputs controlados vs não controlados
- ✅ useState para gerenciamento de estado
- ✅ useRef para referências diretas
- ✅ Eventos onChange, onSubmit
- ✅ Validação de formulários
- ✅ Elevação de estado (lifting state up)
- ✅ Composição de componentes
- ✅ Formulários complexos com múltiplos tipos de input
- ✅ Validação em tempo real
- ✅ Feedback visual de erros
